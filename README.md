# 💻 Sistema de Cálculo em Java

Projeto desenvolvido para praticar lógica de programação utilizando Java.

## 🚀 Funcionalidades

- Entrada de números até digitar 0
- Cálculo da soma
- Cálculo da média
- Contagem de números digitados
- Identificação do maior e menor número
- Menu interativo com opções

## 🛠 Tecnologias

- Java
- Scanner (entrada de dados)

## 📚 Aprendizados

- Estruturas de repetição (for)
- Condicionais (if/else)
- Switch case
- Lógica de programação
